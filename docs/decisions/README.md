# Architecture and Design Decisions

This directory records numbered University-Level Architecture Decision Records (UL-ADRs).

## Convention
- IDs use `UL-ADR-NNNN`, are sequential, and are never reused.
- Accepted decisions alone are authoritative.
- Statuses: Proposed, Accepted, Rejected, Superseded, Deprecated.
- Superseded records retain their original ID and link to the replacement.
- A recommendation is not a decision; explicit Project Owner approval is required.

## Required record fields
Identifier, Title, Status, Context, Decision drivers, Alternatives considered, Decision, Consequences, Approval status, and Date.

The decision register is an index, not a substitute for the full ADR records. Formal records should be added progressively and must accurately reflect the approved decision.
