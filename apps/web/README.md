# Web Application

Planned frontend: Next.js App Router, React, and TypeScript.

R1 implementation focus:
- Build the approved interactive prototype and user journeys here when the application scaffold is authorized.
- Keep UI components reusable, responsive, and accessible.
- Organize application code by feature/business capability.
- Treat the frontend as a presentation layer; it does not enforce authorization or tenant isolation.
- Use simulated fictional data in early prototype/demo workflows.

Do not assume a package manager, UI library, CSS framework, or state/form library has been selected.
